# AI HUB 2.0 — Агрегатор инновационных ИИ-инструментов 🚀

**AI HUB 2.0** — современный, производительный маркетплейс нейронных сетей, AI-ассистентов и стартапов. Дизайн платформы спроектирован в стиле популярного каталога *Future Tools*. Наше решение сочетает в себе элегантный веб-интерфейс на React + TS + Tailwind CSS и автоматизированного поискового робота, который следит за актуальностью базы данных.

---

## ✨ Основной функционал

1. **Раздельные вкладки**: Удобное переключение между аудиториями:
   * **«Для Программистов»**: инструменты повышения производительности, кодинг-ассистенты, API-сервисы.
   * **«Для Всех Пользователей»**: генераторы текста, музыки, картинок, бытовые ИИ-помощники.
2. **Динамический пинг (реальное время)**: При загрузке страницы отправляется фоновый асинхронный запрос к каждому инструменту с таймаутом **5 секунд**. Статусы отображаются прямо в карточке:
   * `Рабочий ✅` — сервис успешно ответил
   * `Нестабильный 🟡` — долгое соединение (таймаут)
   * `Недоступен 🔴` — сетевая ошибка или недоступность домена
3. **Новостная лента стартапов**: Живой виджет справа с подборкой инновационных AI-проектов с **GitHub** и платформы **TatNet**.
4. **Умное Избранное**: Сохранение любимых инструментов в `localStorage` (звёздочки на карточках + фильтр в один клик).
5. **SEO-оптимизация**: Встроенные файлы `sitemap.xml` и `robots.txt` для идеального ранжирования в Google и Яндекс.
6. **Праздничное обновление**: Специальное интерактивное переключение в **Новогодний режим (25 декабря — 10 января)**. В этот период робот подменяет `User-Agent` на `HappyNewYearBot/2.0` и база наполняется праздничными ИИ для генерации открыток, поздравлений и игр. В остальное время года эти ИИ скрываются умным фильтром.

## 🛠 Локальный запуск (Фронтенд)

### Системные требования
Убедитесь, что у вас установлены:
* **Node.js** v18 или выше
* **npm** v9 или выше

### Шаги запуска:
1. Клонируйте репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd ai-hub-2.0
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер разработки VITE:
   ```bash
   npm run dev
   ```
4. Откройте приложение:
   Приложение будет доступно на локальном хосте: [http://localhost:3000](http://localhost:3000)

## 🤖 Поисковый Робот (GitHub Actions)

База данных ИИ-инструментов обновляется автономно с помощью скрипта на Python и GitHub Actions.

### Как это устроено:
* Скрипт `update_ai_list.py` опрашивает все ресурсы, проверяет их сетевой статус и помечает мертвые домены как `"working": false`.
* Также он осуществляет поиск по трендам **GitHub**, **TatNet Startup List** и каталогам.
* Обнаруженные новинки автоматически пушатся в файл `public/tools.json`.

### Настройка GitHub Actions:
Файл конфигурации воркфлоу уже настроен и лежит по пути `.github/workflows/update_ai_list.yml`. Воркфлоу запускается:
1. По встроенному cron-расписанию: **дважды в день в 08:00 и 20:00 UTC**.
2. Вручную через вкладку **Actions -> "Run workflow" (workflow_dispatch)** в интерфейсе GitHub.

#### Шаги для активации на вашем GitHub:
1. Перейдите в настройки репозитория: `Settings -> Actions -> General`.
2. В подразделе `Workflow permissions` выберите **"Read and write permissions"** (чтобы бот мог автоматически пушить обновлённый `tools.json` обратно в вашу ветку `main`).
3. (Опционально) Добавьте токен `GEMINI_API_KEY` в `Settings -> Secrets and variables -> Actions` для беспрепятственного поиска.

## 🌐 Деплой на TatNet

Сайт полностью статичен, что гарантирует сверхбыструю загрузку и высокую надежность. Хостинг на TatNet поддерживает прямую заливку из Git или по протоколу SFTP.

### Способ 1: Сборка и деплой через Git (Рекомендуемый)
1. Соберите оптимизированный бандл для продакшена:
   ```bash
   npm run build
   ```
   В корне проекта появится папка `dist` (или `build`).
2. Настройте веб-сервер в панели хостинга **TatNet Cloud** и укажите в качестве корневой папки сборки директорию `dist`.
3. Примените правила перенаправления для SPA во встроенном Nginx хостинга TatNet:
   ```nginx
   location / {
       try_files $uri $uri/ /index.html;
   }
   ```

### Способ 2: Загрузка через SFTP
1. Подключитесь к выделенному FTP/SFTP серверу TatNet, используя доступы из панели управления.
2. Перенесите всё содержимое вашей папки `dist/` напрямую в корневую директорию `/var/www/html/` или `/public_html/`.
